# Conloq

Organização do projeto **Mash**, desenvolvido como Projeto Integrador III do curso de Desenvolvimento de Software Multiplataforma (DSM3) da FATEC Registro, 2026.

## O projeto

O Mash reúne o acompanhamento da mosturação na produção de cerveja artesanal em um fluxo único: receitas, rampas de temperatura, lotes e leituras do teste de iodo, com histórico rastreável. A proposta está descrita no repositório central do projeto.

## Sobre este repositório

Este é o repositório institucional da organização. Ele não faz parte do runtime HTTP do Mash, não descreve a API e não serve como evidência de que uma funcionalidade do produto existe. O roteiro de execução e o recorte vigente do semestre estão na [conloq/mash#66](https://github.com/conloq/mash/issues/66).
